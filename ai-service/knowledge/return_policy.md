# Return Policy

## Return Eligibility

Customers can request a return within 7 days of delivery for eligible products.

Products must be unused and returned in their original packaging with all accessories, manuals, and included items.

## Non-Returnable Products

The following products are generally not eligible for return:

- Personalized products
- Products damaged by the customer
- Products without the original packaging
- Certain hygiene-sensitive products
- Products explicitly marked as non-returnable

## Return Process

Customers can initiate a return from their order details page.

The system verifies:

1. Whether the order has been delivered.
2. Whether the return window is still active.
3. Whether the product is eligible for return.

If the return request is approved, a pickup may be scheduled.

## Return Window

The standard return window is 7 days from the delivery date.

For example, if an order is delivered on August 1, the customer can normally request a return until August 8.

## Return Status

Customers can track the following return states:

- RETURN_REQUESTED
- RETURN_APPROVED
- PICKUP_SCHEDULED
- PICKED_UP
- RETURN_RECEIVED
- RETURN_REJECTED
- REFUND_INITIATED
- REFUND_COMPLETED
